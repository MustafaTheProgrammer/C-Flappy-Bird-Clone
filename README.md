# C-Flappy-Bird-Clone
This is my first real game programmed with C, and by real I mean one that renders actual graphics and isn't an ASCII game. It's yet another flappy bird clone. This is my next big step in low level game dev with C.

To play this first download the a.out file and them execute it. A window should appear when the program executes. You should click on it to be sure the game captures your inputs. Press the up arrow key to start the game. Press the same key while playing to flap up.
